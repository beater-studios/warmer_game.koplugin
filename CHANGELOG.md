# Changelog

## [0.1.2]

- A full refresh every 9 updates in a game and at the end of each one, so a long game no longer builds up ghosting on e-ink.
- If the game cannot open, a message says so instead of KOReader closing, and the screen rotation is given back.
- The Back key goes back one screen, and the game closes properly when KOReader quits.
- Saved games and statistics from any version are read field by field: a damaged game is dropped and the rest stays.
- A saved daily word that left the vocabulary starts a new game instead of mixing guesses from another word.

## [0.1.1]

- The Warmer cover on the sleep screen while the game is open.

## [0.1.0]

First version.

- Word of the day and free play in Portuguese, English and Spanish, with the interface in the same three languages.
- Each guess shows its position in a ranking of closeness in meaning, with a bar on a log scale.
- The game's own keyboard, always on screen; accents are optional and plurals count as their singular.
- A word sent again turns the list to its page and is marked as already sent.
- Hints halfway to the secret word, giving up with the 100 closest words revealed.
- Streak, wins and average guesses by language, and the daily result as a QR code without revealing any word.
- Three package sizes, with 100, 150 (recommended) and 300 dimensions.
